# Security policy

AccessJourney 0.1 is an early local developer tool. Journey files can interact with real websites; run trusted files against environments you are allowed to test. It is not designed as a public scanning server or a security boundary.

Do not file public issues containing secrets, private URLs, report artifacts, or exploit details affecting others. If available, use GitHub's private vulnerability reporting for this repository. Otherwise use the contact options at https://awanioai.com and request a private channel before sending details. No response-time guarantee is offered.

Reports escape dynamic HTML and omit raw node HTML and form values. Optional screenshot masking is best-effort. Review all artifacts before sharing. Chromium and dependencies need updates; use a disposable test environment for untrusted websites.
