# Roadmap

This is a direction, not a delivery promise.

## v0.1 — Reproducible journey evidence

- JSON journey execution and viewport isolation
- axe findings and manual-review items per state
- HTML/JSON/Markdown reports
- baseline regression gate
- opt-in keyboard focus traces and masked screenshots
- synthetic integration fixture and CI

## Next: usability and evaluation

- Gather feedback from disabled users and accessibility practitioners.
- Add actionable guidance for the most frequent rules.
- Add fixtures for focus return, validation announcements, menus, and responsive navigation.
- Test reports with screen readers and keyboard-only navigation; publish findings and remaining issues.
- Make a visual recorder that exports reviewable journey files.

## Later, based on demand

- Explicit focus assertions and guided keyboard-trap investigation
- Baseline migration and reviewed suppressions with reasons and expiry
- Firefox/WebKit support and authenticated test-state handling
- An accessible report viewer with manual observations and issue exports
- Optional local integrations for assistants, using the same documented report schema

No existing private project will be used as a fixture or republished.
