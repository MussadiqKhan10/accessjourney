Manual review checklist

  • Complete the journey using only the keyboard. Check logical focus order and visible focus.
  • Check dialog focus entry, containment, Escape behavior, and return to the trigger.
  • Use a screen reader to check names, instructions, validation errors, and live announcements.
  • Check zoom, reflow, touch targets, and meaningful alternative text with people who use assistive technology.
